## Suggested Review Routine
1. Read the challenge README and expected output first.
2. Open `schema.sql` to understand the tables and sample data.
3. Write or inspect `solution.sql` without running it immediately.
4. Run the combined schema + solution command from the repository root.
5. Compare the output to the challenge README.
